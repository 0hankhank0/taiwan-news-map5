08 · 移植指南

將以下 CSS 變數貼入 index.html 的 :root 取代原有的色彩 Token，圖示 SVG 直接替換原本的 Font Awesome 類別即可。

/* ── 台灣即時事件地圖 VI Token — 可直接貼入 :root ── */ --brand-crimson: #C0392B; /* 警示紅 · 緊急事件主視覺 */ --brand-crimson-glow: rgba(192,57,43,0.18); --brand-incense: #D35400; /* 香火橙 · 中度警示 */ --brand-candle: #E8A020; /* 燭光金 · 悼念情感 */ --brand-muyu: #7D5A3C; /* 木魚棕 · 佛寺文化 */ --cat-disaster: #C0392B; --cat-criminal: #8E44AD; --cat-traffic: #2471A3; --cat-medical: #D35400; --cat-activity: #1E8449; --cat-other: #4A5878; --bg-void: #060A14; --bg-deep: #0C1120; --bg-panel: #101828; --bg-card: #162035; --font-body: "Space Grotesk", sans-serif; --font-display: "Noto Serif TC", serif; --font-mono: "JetBrains Mono", monospace;
